# CapCut Pro Max — مشروع Android أولي

هذه نسخة تأسيسية وليست نسخة مونتاج مكتملة بعد.

## الموجود حالياً
- تطبيق Android أصلي باسم CapCut Pro Max.
- اختيار فيديو من الهاتف ومعاينته داخل التطبيق.
- واجهة عربية أولية لأدوات القص والصوت والنص والمؤثرات والتصدير.

## ما لم يُفعّل بعد
أزرار القص والصوت والنص والمؤثرات والتصدير حالياً عناصر واجهة فقط. لا يوجد حتى الآن محرك مونتاج أو تصدير 4K فعلي. سيتم تنفيذ ذلك في مراحل لاحقة باستخدام محرك معالجة فيديو مناسب، مع مراعاة قدرة الهاتف ومساحة التخزين.

## بناء APK
يمكن فتح المشروع في Android Studio ثم بناء APK من:
Build > Build Bundle(s) / APK(s) > Build APK(s)

يوجد أيضاً ملف GitHub Actions لبناء APK تلقائياً بعد رفع المشروع إلى مستودع GitHub وتشغيل workflow يدوياً.

## المتطلبات
- Android Studio حديث
- JDK 17
- Android SDK Platform 35
